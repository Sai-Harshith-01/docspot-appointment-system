## Getting Started

### Prerequisites
- Node.js (v16+ recommended)
- npm or yarn
- MongoDB (local or cloud, e.g., MongoDB Atlas)

### Backend Setup

1. Go to the backend folder:
   ```
   cd Project\ Files/backend
   ```
2. Install dependencies:
   ```
   npm install
   ```
3. Copy `.env.example` to `.env` and fill in your values:
   ```
   cp .env.example .env
   ```
4. Start the backend server:
   ```
   npm start
   ```

### Frontend Setup

1. Go to the frontend folder:
   ```
   cd Project\ Files/frontend
   ```
2. Install dependencies:
   ```
   npm install
   ```
3. Start the frontend server:
   ```
   npm start
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser.

### Notes
- Make sure your backend is running before using the frontend.
- If your backend runs on a different port or URL, update the API URLs in the frontend code accordingly.
